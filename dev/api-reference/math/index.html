    math

    Mathematical functions for EasyScience Parameter objects.

    Every public function takes one or more Parameter objects and returns a new Parameter holding

    • the value, evaluated by Scipp (which also validates the units),
    • the propagated variance (first-order "delta method", uncorrelated inputs), and
    • the fitting bounds, i.e. the exact range the function can take when its argument stays inside the argument's own bounds.

    Conventions:

    • Values are validated strictly. A value outside the function's domain, or a non-finite result, raises ValueError; such values would break a fit loop.
    • Bounds are permissive. They never raise: bounds outside the domain are clipped to it, infinite bounds are accepted, tan bounds that cross an asymptote become (-inf, inf), and bounds that collapse to (nearly) a single number are padded by a relative 2e-9 around the value.

    Input and result classes:

    Every function accepts a DescriptorNumber or a Parameter (a Parameter is a DescriptorNumber), including user subclasses of either. The result is a Parameter, with bounds, if any argument is a Parameter, and a DescriptorNumber, without bounds, otherwise. It is always the base class and never the subclass, as for the arithmetic operators. A DescriptorNumber argument counts as the single point at its value when the bounds of a Parameter result are derived.

    Using es.math in a model:

    es.math works on scalar Parameter objects, so it cannot be applied over an x array. Use it to derive scalar quantities, with their uncertainty, from the parameters of a model or of a fit. Each result is a new Parameter that is a snapshot of its inputs: it does not follow later changes. Inside a model, derive it in __call__ so that it is recomputed on every evaluation of the fit, and not once in __init__:

    class GaussianPeak(ModelBase):
    def sigma(self):
        two = self._two
        return self._fwhm / (2 * es.math.sqrt(2 * es.math.log(two)))

    def __call__(self, x):
        sigma = self.sigma().value  # derived on every evaluation
        shift = (x - self.center.value) ** 2
        return self.amplitude.value * np.exp(-shift / (2 * sigma**2))

    Two things to keep in mind. Propagated variances assume uncorrelated inputs, because a Parameter stores a variance but no covariance; a function of two strongly correlated fit parameters (for example arctan2 of the slope and intercept of a line) can be off by a large factor. And a fit reports different uncertainties for different minimizers, so every derived variance is only as good as the variance it starts from.

    Implementation: each function is described by a small, immutable _MathOp specification (which Scipp function to call, which domain it accepts, how to derive its bounds, ...). A single dispatcher, _apply, does the work for all of them, so adding a function means adding a specification, not new control flow.

    The public entry point is easyscience.math (es.math), which re-exports the names in __all__. They are also available from easyscience.variable.

    exp(x)

    Calculate the exponential, e**x, of a dimensionless parameter.

    Parameters:

    Name Type Description Default
    x _D

    Dimensionless input.

    		 required

    Returns:

    Type Description
    _D

    Parameter or DescriptorNumber exp(x) with propagated variance and bounds (exp(x.min), exp(x.max)). The class follows the inputs: a Parameter (with bounds) if any argument is one, otherwise a DescriptorNumber (without bounds).

    Raises:

    Type Description
    TypeError

    If x is not a Parameter or DescriptorNumber.
    UnitError

    ValueError

    If the result overflows (x greater than about 709.78) or, when x has a variance, if the propagated variance overflows. The variance scales with exp(2x), so that happens from about 355 for a unit variance.

    Examples:

    >>> import easyscience as es

>>> print(f'{result.value:.4f} in [{result.min:.4f}, {result.max:.4f}]')
2.7183 in [1.0000, 7.3891]

    The variance is propagated (first order):

    >>> x = es.Parameter('x', 0.0, variance=0.01)
>>> result = es.math.exp(x)
>>> print(f'{result.value:.4f}, variance {result.variance:.4f}')
1.0000, variance 0.0100

    tan(x)

    Calculate the trigonometric tangent of an angle parameter.

    Parameters:

    Name Type Description Default
    x _D

    Angle, with unit rad or deg.

    		 required

    Returns:

    Type Description
    _D

    Parameter or DescriptorNumber Dimensionless tan(x) with propagated variance and bounds. The class follows the inputs: a Parameter (with bounds) if any argument is one, otherwise a DescriptorNumber (without bounds).

    Raises:

    Type Description
    TypeError

    If x is not a Parameter or DescriptorNumber.
    UnitError

    If the unit of x is not an angle.
    ValueError

    If the value of x is within 1e-7 rad, or one standard deviation if that is larger, of an asymptote (pi/2 + n*pi), where the propagated variance would explode.

    Notes

    The value is guarded against asymptotes, but the bounds are allowed to cross them: if x.min and x.max lie on different branches of tan, the result bounds are (-inf, inf). A bound exactly on an asymptote makes the result bound infinite on that side only, so [0, 90] deg gives [0, inf).

    Examples:

    Angle in radians:

    >>> import easyscience as es
>>> import numpy as np
>>> angle = es.Parameter(
...     'angle', np.pi / 4, unit='rad', min=0.0, max=np.pi / 3
... )
>>> result = es.math.tan(angle)
>>> print(f'{result.value:.4f} in [{result.min:.4f}, {result.max:.4f}]')
1.0000 in [0.0000, 1.7321]

    Angle in degrees; bounds that cross an asymptote (90 deg) become infinite:

    >>> angle = es.Parameter('angle', 45.0, unit='deg', min=0.0, max=120.0)
>>> result = es.math.tan(angle)
>>> print(f'bounds [{result.min:.4f}, {result.max:.4f}]')
bounds [-inf, inf]

    arctan2(
    y: DescriptorNumber,
    x: DescriptorNumber,
    *,
    unit: str = ...,
) -> DescriptorNumber

    Calculate the angle of the point (x, y), using both signs to find the quadrant.

    Parameters:

    Name Type Description Default
    y DescriptorNumber

    Cartesian y-coordinate.

    		 required
    x DescriptorNumber

    Cartesian x-coordinate. Must have the same unit as y.

    		 required
    unit str

    Unit of the returned angle, 'rad' or 'deg'. The value, the variance and the bounds are all converted.

    		 'rad'

    Returns:

    Type Description
    DescriptorNumber

    Parameter or DescriptorNumber Angle in unit ([-pi, pi] rad), with propagated variance and bounds. The class follows the inputs: a Parameter (with bounds) if any argument is one, otherwise a DescriptorNumber (without bounds).

    Raises:

    Type Description
    TypeError

    If y or x is not a Parameter or DescriptorNumber.
    UnitError

    If y and x have different units, or unit is not an angle unit.
    ValueError

    If an argument has a variance and the point (x, y) lies within the larger of the two standard deviations of the origin, where the angle is undefined, or if the result is not finite.

    Warns:

    Type Description
    UserWarning If all four bounds are finite and the box they span
    touches the branch cut.

    Notes

    Scipp does not propagate variances through atan2. EasyScience does it with the delta method, assuming y and x are uncorrelated.

    The bounds are the exact range of the angle over the box [y.min, y.max] x [x.min, x.max]. If the box touches the branch cut (y = 0 with x < 0) the angle jumps between -pi and pi; the bounds are then [-pi, pi], and a UserWarning is raised when all four bounds are finite, since gradient-based minimisers behave badly across the jump.

    Examples:

    The angle of the point (x, y) = (1, 1) m, in radians:

    >>> import easyscience as es
>>> y = es.Parameter('y', 1.0, unit='m', min=0.5, max=2.0)
>>> x = es.Parameter('x', 1.0, unit='m', min=1.0, max=3.0)
>>> result = es.math.arctan2(y, x)
>>> print(
...     f'{result.value:.4f} {result.unit} in [{result.min:.4f}, {result.max:.4f}]'
... )
0.7854 rad in [0.1651, 1.1071]

    Ask for degrees with unit; the value, variance and bounds follow:

    >>> y = es.Parameter('y', 1.0, unit='m', min=0.5, max=2.0)
>>> x = es.Parameter('x', 1.0, unit='m', min=1.0, max=3.0)

    x _D

    Input, with unit rad or dimensionless.

    		 required

    Returns:

    Type Description
    _D

    Parameter or DescriptorNumber Dimensionless sinc(x) (equal to 1 at x = 0) with propagated variance and exact bounds. The class follows the inputs: a Parameter (with bounds) if any argument is one, otherwise a DescriptorNumber (without bounds).

    Raises:

    Type Description
    TypeError

    If x is not a Parameter or DescriptorNumber.
    UnitError

    If the unit of x is neither rad nor dimensionless.

    Notes

    This matches Scipp and the physics convention, not the normalised sin(pi x) / (pi x) of numpy.sinc.

    Examples:

    Angle in radians:

    >>> import easyscience as es
>>> import numpy as np
>>> angle = es.Parameter('angle', np.pi / 2, unit='rad', min=0.0, max=10.0)

>>> print(f'{result.value:.4f} in [{result.min:.4f}, {result.max:.4f}]')
0.6366 in [-0.2172, 1.0000]

    sinc does not accept degrees; convert an angle in degrees first:

    >>> angle = es.Parameter('angle', 90.0, unit='deg')
>>> angle.convert_unit('rad')
>>> result = es.math.sinc(angle)
>>> print(f'{result.value:.4f} in [{result.min:.4f}, {result.max:.4f}]')
0.6366 in [-0.2172, 1.0000]
