# :material-tune-vertical: Advanced Topics

These notebooks go beyond a single least-squares fit. They assume that
you are familiar with the [Fitting](../fitting/index.md) notebooks.

- [Bayesian analysis](../fitting-bayesian.ipynb) – Run Bayesian MCMC
  sampling on a model with EasyScience to obtain full posterior
  distributions for the parameters.
- [Progress Callback](../progress-callback.ipynb) – Monitor fitting
  progress across minimizer backends and update a notebook interface
  while a fit is running.
