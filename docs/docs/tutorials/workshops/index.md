# :material-account-group: Workshops & Schools

These notebooks come from workshops and schools. They walk through the
whole analysis of one data set, from loading the reduced data to the
fit, and are written as exercises for a group.

- [Fitting QENS](../fitting-qens.ipynb) – Fit a quasi-elastic neutron
  scattering (QENS) data set with EasyScience.
- [Fitting SANS](../fitting-sans.ipynb) – Fit a small-angle neutron
  scattering (SANS) data set with EasyScience.

The [Fitting](../fitting/index.md) section covers the same data sets
with model classes and units, and shows how to derive quantities from
the fit.
